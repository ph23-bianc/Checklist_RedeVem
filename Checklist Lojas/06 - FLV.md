# 🥬 FLV (Frutas, Legumes e Verduras)

- [ ] O piso está limpo?
- [ ] As gôndolas estão arrumadas e coloridas? Produtos organizados?
- [ ] Todos os produtos estão precificados?
- [ ] Todos os produtos estão em condições de consumo?
- [ ] O relatório de perdas está sendo atualizado diariamente?
- [ ] Como estão sendo armazenadas as perdas?
- [ ] Há cartazes de oferta?
- [ ] A iluminação está adequada?
- [ ] As mercadorias estão sendo pesadas no recebimento? (relatório de divergências)

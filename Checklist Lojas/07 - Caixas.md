# 💰 Caixas

- [ ] O balcão está limpo e organizado? Os equipamentos?
- [ ] Os produtos estão devidamente abastecidos?
- [ ] Todos os produtos têm preço?
- [ ] O interior do balcão está limpo, organizado e abastecido?
- [ ] A sinalização do caixa está clara para os clientes?
- [ ] A iluminação está adequada?
- [ ] Os uniformes estão limpos?
- [ ] Os cigarros estão devidamente abastecidos? (inventário regular atualizado?)
- [ ] O troco externo e as gavetas são contados no início e no fim do expediente?
- [ ] Os equipamentos estão funcionando corretamente?
